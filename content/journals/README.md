# Engineering Journal

Create each article as `content/journals/article-slug.mdx`.

Required frontmatter:

```yaml
---
title: "Article title"
description: "A concise summary."
date: "2026-10-14"
tags:
  - "Next.js"
  - "Architecture"
published: false
---
```

Keep `published: false` while drafting. Only articles with `published: true` appear on the public journal and article routes.

Use standard Markdown/MDX prose for article content. Verify technical claims and project details before publication.
